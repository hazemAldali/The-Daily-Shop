# مراجعة الملفات وإعادة بناء Gradle — 26-11-2026

## ما تم التحقق منه
- الحزمة: `com.hazem.dailystore`.
- `versionCode=1284` و`versionName=1.0.1`.
- `minSdk=23` و`targetSdk=35` و`compileSdk=35`.
- إصدار Android Gradle Plugin داخل APK هو `8.7.3`.
- Kotlin metadata في الأصناف تشير إلى Kotlin `2.0.0`؛ تم اختيار Kotlin stdlib `2.0.21` كبداية.
- استعاد JADX عدد 5,854 ملف Java و1,102 مورداً بحسب تقرير الاستعادة.
- توجد 132 وحدة Java ضمن حزمة التطبيق `com.hazem.dailystore`.
- قاعدة البيانات تحمل `DATABASE_VERSION=33` وتستخدم SQLCipher.
- توجد مكتبات SQLCipher الأصلية لأربع معماريات: arm64-v8a وarmeabi-v7a وx86 وx86_64.

## بنية البناء الأولية
- ملفات Gradle الأصلية وملف Gradle wrapper غير موجودة في الفرع؛ لذلك أُنشئ هيكل Gradle جديد.
- وحدة التطبيق تشير إلى مصادر JADX والموارد المفكوكة مباشرة بدلاً من نسخ آلاف الملفات.
- استبعاد `R.java` و`BuildConfig.java` المفكوكين لتجنب التعارض مع الأصناف التي يولدها Android Gradle Plugin.
- إصدارات AndroidX مأخوذة من ملفات metadata في APK. إصدارات SQLCipher وOkHttp وBouncyCastle أولية وتحتاج تأكيداً من اختبار البناء.

## حدود مهمة
- ناتج JADX Java تقريبي وليس المصدر الأصلي، وقد يتضمن أخطاء ترجمة.
- ملفات الاختبارات الأصلية وملفات Gradle الأصلية ومفتاح التوقيع غير موجودة ضمن المواد الحالية.
- نجاح إعداد Gradle لا يعني نجاح تجميع التطبيق أو صلاحية APK الناتج.
- لا يمكن تحديث التطبيق المثبت فوق النسخة الحالية دون مفتاح التوقيع الأصلي.
